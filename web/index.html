      Words and shortcuts

      Task
      One GitHub issue, or one pull request to review, that Codeignite is taking through its steps.
      Step
      One part of the path a task follows: triage, reproduce, plan, implement, checks, verify, your review, open the PR. A task moves on only when its step's rule is met.
      Your turn
      The task waits for you: to review and approve, to answer the agent's questions, or to look at repeated failures.
      Board columns
      Understand is triage, reproduce and plan. Build is implement. Check is the checks and the verifier. Ship is opening the pull request. Your turn holds every task that waits for you.
      Check
      A command a project defines, such as its lint or test run. Every check must pass on the committed change. The command line calls a check a "gate".
      Verifier
      A second agent that did not write the change. It runs the checks again and judges the change against the issue.
      Worktree
      The task's own copy of the repository, on its own branch. Agents work there, never in your main checkout.
      Tier
      "Trivial" marks a change of one or two files, which skips reproduce and plan. Everything else is standard.
      factory
      The name of Codeignite's command in the terminal, for example factory status.
